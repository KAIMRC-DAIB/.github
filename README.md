# KAIMRC-DAIB: Department of AI and Bioinformatics

Welcome to the official GitHub organization of the **Department of AI and Bioinformatics (DAIB)** at **King Abdullah International Medical Research Center (KAIMRC)**.

We focus on cutting-edge computational research in:
- Genomics and transcriptomics
- Bioinformatics pipelines
- Machine learning and AI in biomedicine
- Multi-omics integration
- Clinical data analysis

## 🧬 Current Projects

We maintain and develop:
- **NGS workflows** (e.g., RNA-seq, WGS, WES)
- **Machine Learning models** for omics and clinical data
- **Data visualization tools** for biological insights
- **Bioinformatics utilities** (scripts, notebooks, Docker images)
